# Tic-Tac-Toe

Play tic-tac-toe against the computer in your browser. Open `index.html` (or enable GitHub Pages on this repo) — no build step, no dependencies.

- A coin toss decides who begins. You are **X**, the computer is **O**.
- **Beginner**: the computer plays random moves.
- **Average**: the computer plays defensively — it completes its own line if it can, otherwise blocks your threat, otherwise plays randomly. When the computer begins, its first move is random.
